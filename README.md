# Bazar-Dor

Bazar-Dor is a Bangla-based product price information web application built with Next.js. It helps users explore everyday product prices, compare price changes and view market-wise price information through a simple and responsive interface.

# Key Features:

**1. Product Price Overview:** Explore everyday product prices of essential items.
**2. Daily Price Changes:** View products with increased or decreased prices and
                            their percentage changes.
**3. Product Details:** Explore individual product information, including minimum, maximum,
                        and average prices with market-wise price data.
**4. Secure Authentication:** Sign up and sign in using email and password, Google, or GitHub.
**5. Profile Management:** View profile information and update your name.
**6. Responsive Design:** User-friendly experience on mobile phones, tablets, and
                          desktop screens.

## Technologies Used:

1. Next.js
2. React
3. TypeScript
4. Tailwind CSS
5. DaisyUI
6. Better Auth
7. MongoDB
